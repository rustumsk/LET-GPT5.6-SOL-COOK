# Progress log

This directory is the append-only operating history for the experiment. It complements, rather than duplicates, the other records:

- `docs/status.md` is the current weekly snapshot.
- `docs/experiments/` contains hypothesis-specific measurements and decisions.
- `docs/decisions/` contains durable architecture and product decisions.
- `docs/progress/YYYY-MM-DD.md` records what materially changed that day, the evidence, blockers, and the next highest-impact action.

Do not record lead names, email addresses, message bodies, credentials, customer data, or vanity activity. Record aggregate counts and links to GitHub artifacts instead.
