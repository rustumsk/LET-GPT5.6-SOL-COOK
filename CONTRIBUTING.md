# Contributing

Read `AUTONOMOUS_APP_CHARTER.md` and `AGENTS.md` first. Start from a GitHub issue, branch from the intended base, keep one coherent concern per pull request, and use conventional commits. Pull requests must explain the problem, solution, validation, security/privacy impact, migration impact, rollback, and remaining risk.

Never commit credentials, customer data, `.env` files, private keys, or production exports. Report vulnerabilities privately as described in `SECURITY.md`.
